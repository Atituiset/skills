# Category: video

Skills for **producing videos with HyperFrames** — narration, captions, timeline assembly, narrative structure, publishing.

**Belongs here:** anything whose deliverable is a rendered video or a reusable layer of a video-production pipeline, regardless of video type (explainer, promo, recut, motion graphics, …).

**Does not belong here:** general engineering discipline (TDD, code review, debugging), media asset generation unrelated to a video timeline, one-off video project files.

## Skills

| Skill | What it does |
|---|---|
| [bilingual-video](bilingual-video/) | The general layer for **any** bilingual (zh+en) HyperFrames video: dual independent projects, edge-tts/Kokoro narration with native word-boundary captions, the single-line iteration loop, the generated publishing pack, 42 universal pitfalls. |
| [bilingual-tech-explainer](bilingual-tech-explainer/) | Turns a technical article into a **bilingual explainer video for programmers**: wall→fix narrative spine, continuity kit (evolution rail / 0.45s stage scaffolding / wall cards), teaching blueprints. Depends on `bilingual-video`. |
